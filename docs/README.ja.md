博士課程出願のためのオープンソース・プロンプトです。AIと共に指導教員の調査、資金確認、連絡メール、進捗管理を行えます。

**毎日約15分で情報やメールを確認し、次の行動を決めます。初期設定、論文読解、研究計画、正式出願には別途時間がかかります。**

> 毎日の完全な自動処理には、AIプラットフォームが定期実行とメール連携の両方に対応し、許可のもとでメールを読み、下書きし、送信できる必要があります。送信前には本人の承認が必要です。ウェブ検索、ファイル読取、記録の継続保存も確認してください。

## できること

- 指導教員と研究の適合性を具体的な根拠で確認
- 課程、資格、締切、資金の調査
- 個別メールの作成と返信・出願状況の管理

## 使い始める

1. AIプラットフォームでモデルを選ぶ。
2. 完全版プロンプトを新しい会話やプロジェクトに貼り付ける。
3. 研究分野、希望地域、入学年、資金条件、CVを伝える。分けて提供してもよい。
4. 定期実行とメール機能を確認・許可し、日々の進捗を確認する。

## モデルとプラットフォーム

ChatGPT、Claude、Gemini、Kimi、DeepSeekなど、長文プロンプトを扱える環境で使用できます。モデルは各環境で選択します。機能、利用枠、料金は異なり、自動化や送信に非対応の場合は該当部分を手動で行います。

AIを利用した翻訳で、重要なルールを確認しています。解釈が異なる場合は簡体字中国語の原文を参照してください。修正提案を歓迎します。
