博士課程出願のためのオープンソース・プロンプトです。AIと共に指導教員の調査、資金確認、連絡メール、進捗管理を行えます。

**毎日約15分で情報やメールを確認し、次の行動を決めます。初期設定、論文読解、研究計画、正式出願には別途時間がかかります。**

> 毎日の完全な自動処理には、AIプラットフォームが定期実行とメール連携の両方に対応し、許可のもとでメールを読み、下書きし、送信できる必要があります。送信前には本人の承認が必要です。ウェブ検索、ファイル読取、記録の継続保存も確認してください。

## 私たちの考え

調査、検証、連絡、出願をつなぐ完全なワークフローを重視します。モデルは進歩し続けるため、固定の文章型や語数を強制せず、その文章力を信頼します。内容はあなたの研究、希望、判断に基づきます。

- **出願への移行：** 初回に、異なる教員からの有効な A/B 返信 8〜10 件を、新たな連絡を止めて出願へ移る検討の目安として提案します。変更可能で、締切が近ければ達成を待ちません。
- **直接出願も候補に：** 教員の事前同意なしに出願できる課程を調べ、本人の意向に応じて A-DIRECT または B-DIRECT とし、教員の返信とは別に数えます。
- **毎日締切を確認：** メール確認時に出願・奨学金などの締切と残り時間、今日出願準備を始めた場合の時間も示します。

## クラウドでの実行を推奨

**このワークフローには ChatGPT Work を強く推奨します。** デスクトップ版、ウェブ版、モバイル版のいずれでも使え、デスクトップからクラウド Work を開始することもできます。パソコンがオフでも毎朝10時に実行したい場合は、定期タスクと必要な資料・ツールすべてがクラウドで使えるか確認してください。

ローカルファイルやデスクトップアプリに依存する処理は、パソコンがオフやスリープの間に利用・実行できない場合があります。ローカル Codex もパソコンに依存し、Codex Cloud は別のクラウド環境です。どの方法でも定期実行、ウェブ、メール、出願記録へのアクセスを確認し、送信前に本人が承認します。

特にファイルアクセスを確認してください。ChatGPT プロジェクト内で作成した定期タスクは、そのプロジェクトにアップロード・保存したファイルへ直接アクセスできません。タスクが使える場所に記録を置き、タイムゾーンを設定して実際にテストし、次回実行と報告を確認します。利用可否はアカウント、プラン、ワークスペースにより異なります。

例えば、許可されたクラウドファイルや連携サービスで記録を保存し、定期タスクが同じ記録を読み書きできるか試してください。

公式情報：[ChatGPT Work と Codex](https://help.openai.com/en/articles/20001275/) · [ChatGPT の定期タスク](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt) · [Codex Cloud](https://help.openai.com/en/articles/20001545-using-codex-cloud)

## できること

- 指導教員と研究の適合性を具体的な根拠で確認
- 課程、資格、締切、資金の調査
- 個別メールの作成と返信・出願状況の管理

## 使い始める

1. AIプラットフォームでモデルを選ぶ。
2. 完全版プロンプトを新しい会話やプロジェクトに貼り付ける。
3. 研究分野、希望地域、入学年、資金条件、CVを伝える。分けて提供してもよい。
4. 定期実行とメール機能を確認・許可し、日々の進捗を確認する。

## モデルとプラットフォーム

ChatGPT、Claude、Gemini、Kimi、DeepSeekなど、長文プロンプトを扱える環境で使用できます。モデルは各環境で選択します。機能、利用枠、料金は異なり、自動化や送信に非対応の場合は該当部分を手動で行います。

AIを利用した翻訳で、重要なルールを確認しています。解釈が異なる場合は簡体字中国語の原文を参照してください。修正提案を歓迎します。
